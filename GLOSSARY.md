# Algo Visualizer

Учебный проект: Go-библиотека алгоритмов (`algorithms/`) + веб-визуализатор (`visual/`) + CLI-опросник (`quiz/`). Программа обучения — три блока: фундамент, деревья, графы+ДП.

## Language

### Общие термины проекта

**Algorithm**:
Чистая функция или структура данных в `algorithms/`, не знающая о UI. Может работать в «тихом» режиме (просто считает результат) или с эмиттером событий.
_Avoid_:implementation, функция

**Emitter**:
Единый интерфейс, в который алгоритм «стреляет» типизированными событиями во время работы. В тихом режиме не используется (nil-эмиттер).
_Avoid_: recorder, callback (callback — конкретный вид эмиттера)

**Event / Step**:
Типизированное событие, описывающее один атомарный шаг алгоритма (сравнение, обмен, визит вершины). Алгоритм определяет свои типы событий; протокол/emitter — общий.
_Avoid_: log, trace (они подразумевают текстовые логи)

**Quiet mode**:
Работа алгоритма без эмиттера — как обычная библиотечная функция. Основной режим для тестов и переиспользования.
_Avoid_: silent mode, no-ops mode

**Module (учебный модуль)**:
Единица учебной программы: одна тема или связная группа тем. Завершённый модуль включает все применимые части (реализацию, тесты, визуализацию, вопросы квиза); он может быть разбит на несколько тикетов и рабочих сессий. Одна строка в `PROGRESS.md` соответствует одному модулю.
_Avoid_: ticket, задача

**Ticket (тикет)**:
Вертикальный срез реализации с проверяемым результатом; один worktree и одна ветка соответствуют одному тикету. Несколько тикетов могут вместе завершать учебный модуль.
_Avoid_: module, учебный модуль

**Block (блок программы)**:
Группа модулей: Блок 1 «Фундамент», Блок 2 «Деревья», Блок 3 «Графы + ДП».
_Avoid_: chapter, раздел

**Hash Table (хеш-таблица)**:
Структура для хранения пар «ключ — значение», которая выбирает корзину по результату хеш-функции.
_Avoid_: map (кроме имени типа Go), ассоциативный массив

**Bucket (корзина)**:
Позиция в массиве хеш-таблицы, в которую хеш-функция направляет ключ; при методе цепочек корзина может содержать несколько записей.
_Avoid_: слот

**Collision (коллизия)**:
Ситуация, когда разные ключи отображаются в одну корзину.
_Avoid_: конфликт (слишком общее)

**Separate Chaining (метод цепочек)**:
Способ разрешения коллизий, при котором записи одной корзины хранятся в связанной последовательности.
_Avoid_: открытая адресация

**Bubble Sort (сортировка пузырьком)**:
Сравнивает соседние элементы и меняет местами пару, если она расположена не по порядку; повторяет проходы, пока массив не отсортирован.
_Avoid_: сортировка пузырьков

**Selection Sort (сортировка выбором)**:
На каждом проходе находит минимум неотсортированной части и помещает его в её начало; стандартный вариант может менять относительный порядок равных элементов.
_Avoid_: выборочная сортировка

**Insertion Sort (сортировка вставками)**:
Поддерживает отсортированный префикс и вставляет в него очередной элемент, сдвигая большие значения; при сдвиге только строго больших элементов сортировка устойчива.
_Avoid_: вставочная сортировка

**Insertion Gap (дырка вставки)**:
Временно свободная позиция в отсортированном префиксе, в которую после сдвига больших значений вправо помещается удерживаемый ключ.

**Stable Sort (устойчивая сортировка)**:
Сортировка, сохраняющая исходный относительный порядок элементов с равными ключами.

**In-place Sort (сортировка на месте)**:
Сортировка, которая переупорядочивает переданную коллекцию без создания дополнительной коллекции размера, пропорционального входу.

### Процессы

**Orchestrator (Оркестратор)**:
Основная сессия агента, с которой общается пользователь. Управляет потоком из `docs/WORKFLOWS.md`, спавнит субагентов, ведёт статусы. Код от себя не пишет.
_Avoid_: manager, main agent

**Subagent (Субагент)**:
Агент, запущенный оркестратором для специализированной задачи (ревью, реализация). Пользователь с ним не контактирует, результаты возвращаются оркестратору.
_Avoid_: worker, helper

**Checkpoint (Чекпойнт, Ч1–Ч4)**:
Точка потока, где оркестратор останавливается и ждёт явного подтверждения пользователя: спека, тикеты, находки ревью, мерж. Всё остальное автоматизировано.
_Avoid_: gate, approval step

**Flow (Поток)**:
Сценарий процесса под тип работы: A — полный модуль, B — только квиз, C — баг-фикс, D — рефакторинг и процессные/документационные тикеты. Описаны в `docs/WORKFLOWS.md`.
_Avoid_: pipeline, сценарий (кроме заголовка WORKFLOWS.md)

**Backlog (бэклог)**:
Короткий список низкоприоритетных улучшений кода и рефакторинга, замеченных по ходу работы (`docs/BACKLOG.md`); баги и новые фичи в него не попадают. Разбирается на шаге очистки бэклога между модулями (см. `docs/WORKFLOWS.md`).
_Avoid_: техдолг (шире — включает баги), todo-лист

**Friction-лог (лог трения)**:
Короткий лог трения процесса — неудобств agent-workflow, замеченных по ходу работы (`docs/FRICTION_LOG.md`). Отличается от бэклога: фиксирует трение самого процесса, а не улучшения кода. Правила фиксации и триажа — в `docs/WORKFLOWS.md` → «Friction-лог», формат и статусы записей — в `docs/FRICTION_LOG.md`.
_Avoid_: фрикция, фрикшн-лог, список задач

### Визуализатор

**Visualizer (Визуализатор)**:
Веб-приложение (Go-сервер + TS-фронтенд), которое запускает алгоритм с эмиттером и рисует его выполнение.
_Avoid_: visual/, frontend (это имя слоя, не сущность)

**Run**:
Один запуск алгоритма с входными данными: последовательность событий от запуска до конца (или остановки пользователем).
_Avoid_: session, execution, запуск

**Frame / Кадр**:
Снимок визуализации на момент события. Frontend получает поток кадров и рисует их последовательно.
_Avoid_: state, snapshot

**Frame Renderer**:
Адаптер «события алгоритма → кадр для UI» на бэкенде, своя версия под каждый визуализируемый алгоритм (см. ADR-0002).
_Avoid_: mapper, serializer

### Квиз

**Quiz (Квиз)**:
Интерактивный CLI-опросник по темам программы обучения; вопросы сгруппированы по блокам и модулям.
_Avoid_: тест (слишком перегружено), опросник (оставляем как русское имя, не как термин кода)

**Quiz Question (Вопрос квиза)**:
Единица квиза: текст, варианты (или свободный ввод), правильный ответ, пояснение, ссылка на модуль.
_Avoid_: задание, exercise

**Quiz Bank**:
Хранилище вопросов, сгруппированные по блокам/модулям (embedded-файлы или код).
_Avoid_: вопросы.go, question store
