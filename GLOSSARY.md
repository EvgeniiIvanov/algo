# Algo Visualizer

Учебный проект: Go-библиотека алгоритмов (`algorithms/`) + веб-визуализатор (`visual/`) + CLI-опросник (`quiz/`). Программа обучения — три блока: фундамент, деревья, графы+ДП.

## Language

### Общие термины проекта

**Algorithm**:
Чистая функция или структура данных в `algorithms/`, не знающая о UI. Может работать в «тихом» режиме (просто считает результат) или с эмиттером событий.
_Avoid_:implementation, функция

**Emitter**:
Единый интерфейс, в который алгоритм «стреляет» типизированными событиями во время работы. В тихом режиме не используется (nil-эмиттер).
_Avoid_: recorder, callback (callback — конкретный вид эмиттера)

**Event / Step**:
Типизированное событие, описывающее один атомарный шаг алгоритма (сравнение, обмен, визит вершины). Алгоритм определяет свои типы событий; протокол/emitter — общий.
_Avoid_: log, trace (они подразумевают текстовые логи)

**Quiet mode**:
Работа алгоритма без эмиттера — как обычная библиотечная функция. Основной режим для тестов и переиспользования.
_Avoid_: silent mode, no-ops mode

**Module (учебный модуль)**:
Единица планирования: один алгоритм/тема = реализация + тесты + поддержка в визуализаторе + вопросы квиза. Одна сессия с агентом = один модуль.
_Avoid_: ticket, задача

**Block (блок программы)**:
Группа модулей: Блок 1 «Фундамент», Блок 2 «Деревья», Блок 3 «Графы + ДП».
_Avoid_: chapter, раздел

### Визуализатор

**Visualizer (Визуализатор)**:
Веб-приложение (Go-сервер + TS-фронтенд), которое запускает алгоритм с эмиттером и рисует его выполнение.
_Avoid_: visual/, frontend (это имя слоя, не сущность)

**Run**:
Один запуск алгоритма с входными данными: последовательность событий от запуска до конца (или остановки пользователем).
_Avoid_: session, execution, запуск

**Frame / Кадр**:
Снимок визуализации на момент события. Frontend получает поток кадров и рисует их последовательно.
_Avoid_: state, snapshot

**Frame Renderer**:
Адаптер «события алгоритма → кадр для UI» на бэкенде, своя версия под каждый визуализируемый алгоритм (см. ADR-0002).
_Avoid_: mapper, serializer

### Квиз

**Quiz (Квиз)**:
Интерактивный CLI-опросник по пройденным модулям.
_Avoid_: тест (слишком перегружено), опросник (оставляем как русское имя, не как термин кода)

**Quiz Question (Вопрос квиза)**:
Единица квиза: текст, варианты (или свободный ввод), правильный ответ, пояснение, ссылка на модуль.
_Avoid_: задание, exercise

**Quiz Bank**:
Хранилище вопросов, сгруппированные по блокам/модулям (embedded-файлы или код).
_Avoid_: вопросы.go, question store
