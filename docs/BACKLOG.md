# BACKLOG.md — заметки об улучшениях

Короткий список низкоприоритетных улучшений кода и рефакторинга, замеченных по ходу работы. Заметил — добавил строку; разобрали — удалили.

Правила:

- Одна строка на запись: **область → что улучшить → зачем**.
- Только улучшения без смены поведения: баги — поток C, новые фичи — обычные тикеты, сюда не попадают.
- Без статусов, планов и назначений: запись — заметка, а не тикет.

Разбор списка — отдельный шаг между учебными модулями; порядок см. в разделе «Шаг очистки бэклога» файла `docs/WORKFLOWS.md`.

## Записи

- Сортировки (render, server, frontend и их тесты) → обвязка bubble и selection sort дублируется: тонкие HTTP-обработчики, сборщики URL, SSE-хелперы и каркасы тестов различаются только именем алгоритма → к концу модуля «Простые сортировки» (insertion sort — тикет 21) копий станет три; обобщить на шаге очистки бэклога, а не сейчас.
