# Разделение слоёв: библиотека алгоритмов ничего не знает о визуализации

Алгоритмы — переиспользуемая библиотека (`algorithms/`, обычные Go-пакеты). Визуализация — отдельный слой (`visual/`), потребляющий события. Чтобы алгоритм мог визуализироваться, он принимает необязательный **Emitter** и стреляет в него типизированными **событиями** (сравнение, обмен, визит вершины). Без эмиттера алгоритм работает как обычная библиотечная функция (quiet mode) — на этом режиме гоняются тесты и любое переиспользование.

Вариант «визуализатор дублирует логику алгоритма в обёртке» отвергнут: двойное сопровождение и расхождение логики гарантированы. Вариант «алгоритм как state machine» отвергнут как неестественный для Go.

Последствия: у каждого визуализируемого алгоритма появляется небольшой код эмитирования событий; шаги — данные, поэтому слой визуализации можно менять/переписывать, не трогая алгоритмы.

## Considered Options

- **Emitter + типизированные события** (выбрано): код алгоритмов остаётся естественным, events опциональны.
- **Зеркальная обёртка**: визуализатор повторяет логику сам — отвергнуто (дублирование).
- **State machine** (`func() (Step, bool)`): отвергнуто — неудобно и неидиоматично.
