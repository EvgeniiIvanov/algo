# Документация реализованных алгоритмов и структур

Учебные объяснения того, как устроены алгоритмы и структуры из библиотеки
`algorithms/`. Схемы и описания отражают **реализованные варианты**: quiet mode
и режим наблюдения дают один и тот же результат (тихий режим — тот же цикл
с `nil`-эмиттером, см. ADR-0001), поэтому описан единый алгоритм, а события
упоминаются там, где это помогает пониманию.

## Поиск и сортировки

| Тема | Документация | Реализация |
|------|--------------|------------|
| Бинарный поиск | [Поиск](search.md) | `algorithms/search/` |

| Merge sort, quicksort | [Merge sort и quicksort](merge-quicksort.md) | `algorithms/sort/` |
