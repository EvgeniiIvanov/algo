# 01: Бинарный поиск как библиотека

**What to build:** первый Algorithm в библиотеке — бинарный поиск. Пользователь-разработчик импортирует пакет и вызывает поиск как обычную функцию (quiet mode); может передать Emitter и получить поток типизированных событий шагов (сравнение с серединой, сдвиг границ, найдено/не найдено). Заодно: старый однофайловый `main.go` удаляется, структура слоёв (`algorithms`, `visual`, `quiz`) фиксируется пустыми директориями-местами.

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [ ] Quiet mode: поиск возвращает индекс найденного элемента и -1 для отсутствующего; пустой вход и вход из одного элемента обрабатываются корректно
- [ ] Emitter: при передаче эмиттера алгоритм стреляет типизированными событиями каждого шага; без эмиттера — ни одного вызова, нулевые накладные расходы
- [ ] Тесты шва 1 (публичный API, quiet mode): результаты, граничные случаи, отсутствие элемента
- [ ] Тест события: тестовый рекордер фиксирует ожидаемую последовательность событий на известном входе
- [ ] Комментарии на русском объясняют идею алгоритма и сложность
- [ ] Старый `main.go` удалён, `go vet ./...` и `go test ./...` зелёные
