# 02: Кадры + SSE-эндпоинт

**What to build:** серверная часть визуализатора. Frame Renderer превращает события бинарного поиска в кадры: снимок массива, подсветка активных элементов, текст пояснения на русском. HTTP-сервер принимает запрос на Run (входные данные — массив и искомое значение) и стримит кадры по SSE до конца выполнения. Демо — `curl` на эндпоинт показывает читаемый поток кадров.

**Blocked by:** 01 (Бинарный поиск как библиотека).

**Status:** ready-for-agent

- [ ] Каждый кадр самодостаточен: состояние массива + подсветки + пояснение; клиенту не нужно накапливать состояние
- [ ] SSE-стрим: кадры идут в порядке выполнения, поток завершается после последнего кадра
- [ ] Невалидный вход (неотсортированный массив, мусор) даёт понятную ошибку, а не кадры с мусором
- [ ] Тесты шва 2: интеграционный тест читает SSE-поток и сверяет последовательность кадров с ожидаемой на известном входе
- [ ] Frame Renderer изолирован: добавление следующего алгоритма не требует правок транспортного слоя
