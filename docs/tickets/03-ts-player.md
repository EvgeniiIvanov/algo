# 03: TS-фронтенд — плеер кадров

**What to build:** визуализатор в браузере. Vite + ванильный TypeScript: страница со списком доступных визуализаций (пока одна — бинарный поиск), поле ввода для своих данных, отрисовка кадров (массив с подсветками и пояснением) и плеер: play/pause, скорость, шаг вперёд/назад. Пользователь запускает сервер, открывает страницу, вводит данные и смотрит выполнение алгоритма в своём темпе.

**Blocked by:** 02 (Кадры + SSE-эндпоинт).

**Status:** done

- [ ] Кадр отрисовывается как есть: тупой рендерер, без накопления состояния на клиенте
- [ ] Плеер: play/pause, регулятор скорости, шаг вперёд/назад по уже полученным кадрам, перемотка к любому шагу
- [ ] Ввод своих данных перезапускает Run с новым SSE-соединением
- [ ] UI-тексты на русском
- [ ] Сборка фронтенда не требуется для разработки сервера и наоборот (слои собираются независимо)
- [ ] Демо-сценарий глазами: открыл страницу → ввёл массив и цель → посмотрел анимацию → перемотал назад
