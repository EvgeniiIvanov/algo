# 04: CLI-квиз

**What to build:** интерактивный Quiz в терминале. Пользователь выбирает блок, отвечает на вопросы (4 варианта, один правильный), сразу читает пояснение к ответу, в конце — сводка по блоку. Вопросы хранятся в embedded Quiz Bank, привязаны к модулям. Независим от визуализатора.

**Blocked by:** None (can start immediately).
