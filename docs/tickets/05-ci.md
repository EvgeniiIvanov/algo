# 05: CI на GitHub Actions

**What to build:** при каждом push в `main` и в каждом PR GitHub сам прогоняет проверки: форматирование (gofmt), `go vet`, линтер (golangci-lint) и тесты. Красная галочка — сигнал «не мержить». Никакой сборки артефактов.

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [ ] Workflow запускается на push в `main` и на все pull request'ы
- [ ] Шаг gofmt: падает, если есть неотформатированные файлы (выводит список)
- [ ] Шаг `go vet ./...`
- [ ] golangci-lint (дефолтный набор линтеров, без конфига — добавим при первой боли)
- [ ] Шаг тестов: `go test ./...`
- [ ] Go-версия берётся из `go.mod` (один источник правды)
- [ ] Нет сборки артефактов, Docker, деплоя — только проверки
- [ ] Workflow зелёный на самом PR тикета (dogfooding: первая проверка CI — на его собственном PR)
