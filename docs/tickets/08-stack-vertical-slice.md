# 08: Стек сквозным срезом (библиотека + визуализация)

**What to build:** стек работает в визуализаторе end-to-end: пользователь вводит сценарий операций (`push 5`, `push 7`, `pop` — по одной на строку), выбирает структуру «стек» и наблюдает выполнение по кадрам: содержимое ячейками, подсветка затронутого элемента, указатель top, пояснение к каждому шагу. Тикет несёт всю новую инфраструктуру модуля: пакет `structures`, kind кадра «structure», ввод сценария и выбор структуры на фронте. Спека: `docs/SPEC.md`, секция модуля «Списки, стек и очередь».

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

`автор-черновик: человек` — черновик Stack (структура + события) пишет пользователь; агент дорабатывает по находкам ревью, молча не переписывает.

## Acceptance Criteria

- [ ] Пакет `algorithms/structures`: Stack — Push/Pop/Peek/Len; Pop/Peek из пустого — ошибка, не паника; quiet mode без эмиттера, нулевые накладные расходы
- [ ] Типизированные события операций через Emitter (ADR-0001): атомарный шаг — что записали/удалили и по какому индексу
- [ ] Тесты шва 1: поведение операций, инвариант LIFO, граничные случаи (пустой стек, чередование push/pop); эмиттер-шпион фиксирует ожидаемую последовательность событий на известном сценарии
- [ ] Новый Kind кадра «structure» в конверте Frame (транспорт не правится): снимок = идентичность структуры + значения + подсветки с ролью (добавлен/удалён) + указатели (top) + имя операции; пояснение на русском
- [ ] Маршрут `GET /api/run/stack` по шаблону трейсера: парсинг сценария → валидация → runStreaming; ошибки входа — понятным сообщением до старта Run
- [ ] Тест шва 2: сценарий → чтение SSE-потока → сравнение последовательности кадров с ожидаемой
- [ ] Фронт: поле сценария операций, выбор структуры (пока один пункт — «стек»); существующий сценарий бинарного поиска не ломается
- [ ] Фронт: ветка рендера нового kind'а — непрерывные ячейки с подсветками и указателем top; существующая ветка `array` не тронута
- [ ] Тесты шва 4: рендер кадра kind'а «structure», парсинг сценария, ошибки ввода
- [ ] `go build/vet/test` и фронт lint/test/build зелёные (как в CI)

## Notes

- Ёмкость слайса в кадрах не показываем — амортизация через текст пояснений и будущий квиз (тикет 12).
- Элементы — int, без generics.
