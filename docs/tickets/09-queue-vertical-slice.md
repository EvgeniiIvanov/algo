# 09: Очередь сквозным срезом

**What to build:** очередь появляется в визуализаторе поверх инфраструктуры тикета 08: выбор «очередь», сценарий (`enqueue 3`, `dequeue`), кадры с указателями head/tail и пояснениями. В библиотеку добавляется Queue (Enqueue/Dequeue/Len) с событиями. Спека: `docs/SPEC.md`, секция модуля «Списки, стек и очередь».

**Blocked by:** 08 (стек сквозным срезом — инфраструктура модуля).

**Status:** ready-for-agent

`автор-черновик: человек` — черновик Queue пишет пользователь; выбор реализации (голова-индекс, кольцевой буфер) — его решение в черновике.

## Acceptance Criteria

- [ ] Queue в пакете `algorithms/structures`: Enqueue/Dequeue/Len; Dequeue из пустой — ошибка, не паника; quiet mode
- [ ] Типизированные события операций (ADR-0001); эмиттер-шпион фиксирует последовательность на известном сценарии
- [ ] Тесты шва 1: инвариант FIFO, граничные случаи (пустая очередь, чередование enqueue/dequeue)
- [ ] Frame Renderer очереди поверх kind'а «structure»: указатели head/tail, подсветки операции, пояснение на русском
- [ ] Маршрут `GET /api/run/queue` по шаблону: парсинг → валидация → runStreaming
- [ ] Тест шва 2: ключевой FIFO-сценарий → SSE-поток → ожидаемая последовательность кадров
- [ ] Фронт: опция «очередь» в выборе структуры; ветка рендера переиспользуется без правок стека
- [ ] `go build/vet/test` и фронт lint/test/build зелёные

## Notes

- Если реализация — кольцевой буфер, в кадрах всё равно логическое содержимое (порядок dequeue), не физическая раскладка буфера.
