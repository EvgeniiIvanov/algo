# 09: Очередь сквозным срезом

**What to build:** очередь появляется в визуализаторе поверх инфраструктуры тикета 08: выбор «очередь», сценарий (`enqueue 3`, `dequeue`), кадры с указателями head/tail и пояснениями. В библиотеку добавляется Queue (Enqueue/Dequeue/Len) с событиями. Спека: `docs/SPEC.md`, секция модуля «Списки, стек и очередь».

**Blocked by:** 08 (стек сквозным срезом — инфраструктура модуля).

**Status:** done

`автор-черновик: человек` — черновик Queue пишет пользователь; выбор реализации (голова-индекс, кольцевой буфер) — его решение в черновике.

**Решение по реализации (черновик пользователя):** очередь **фиксированной ёмкости** — `NewQueue(max)` (*Queue, error; отрицательная ёмкость — ошибка), Enqueue в полную — `ErrQueueFull`, Dequeue из пустой — `ErrQueueEmpty`. Dequeue **сдвигает** оставшиеся элементы влево (`O(n)`) — наивная цена dequeue сохранена из черновика как учебная цель модуля (виден сдвиг значений). Дополнительно Peek/IsEmpty/IsFull/Clear. Кадр несёт логическое содержимое (голова → хвост), ёмкость и указатели head/tail; при модели со сдвигом голова всегда в ячейке 0, хвост — последняя занятая ячейка.

**Решение по именам (пользователь):** конструктор стека переименован `structures.New` → `structures.NewStack`; очередь — `NewQueue`. Поведение стека не менялось.
