# 10: Список на слайсе сквозным срезом

**What to build:** список на слайсе появляется в визуализаторе: выбор «список», сценарий (`insert 1 9`, `remove 0`), кадры с подсветкой сдвигаемых элементов — видно, что вставка в середину стоит O(n). В библиотеку добавляется List (Insert/RemoveAt/Get/Len) с событиями. Спека: `docs/SPEC.md`, секция модуля «Списки, стек и очередь».

**Blocked by:** 09 (очередь сквозным срезом).

**Status:** ready-for-agent

`автор-черновик: человек` — черновик List пишет пользователь.

## Acceptance Criteria

- [ ] List в пакете `algorithms/structures`: Insert/RemoveAt/Get/Len; индекс вне границ — ошибка, не паника; quiet mode
- [ ] Типизированные события (ADR-0001): запись/удаление по индексу и сдвиг диапазона — достаточно, чтобы рендерер построил кадр, не зная внутренностей
- [ ] Тесты шва 1: поведение операций, граничные случаи (вставка в голову/хвост, удаление последнего, индекс вне границ); эмиттер-шпион на известном сценарии
- [ ] Frame Renderer списка поверх kind'а «structure»: подсветка сдвигаемых элементов (роль «сдвинут»), пояснение на русском
- [ ] Маршрут `GET /api/run/list` по шаблону: парсинг → валидация → runStreaming
- [ ] Тест шва 2: сценарий со вставкой в середину → SSE-поток → ожидаемая последовательность кадров
- [ ] Фронт: опция «список» в выборе структуры; ветка рендера переиспользуется
- [ ] `go build/vet/test` и фронт lint/test/build зелёные
