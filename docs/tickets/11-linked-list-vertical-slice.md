# 11: Односвязный список сквозным срезом

**What to build:** односвязный список появляется в визуализаторе: выбор «связный список», сценарий (`prepend 4`, `append 7`, `insert 1 9`, `remove 0`, `find 7`), кадры **узлами со стрелками next** — видно, что память не непрерывна и обход идёт узел за узлом (подсветка текущего узла при find/insert/remove). В библиотеку добавляется LinkedList на указателях с событиями обхода и переключения связей. Спека: `docs/SPEC.md`, секция модуля «Списки, стек и очередь».

**Blocked by:** 10 (список на слайсе сквозным срезом).

**Status:** ready-for-agent

`автор-черновик: человек` — черновик LinkedList пишет пользователь.

## Acceptance Criteria

- [ ] LinkedList в пакете `algorithms/structures`: Prepend/Append/InsertAt/RemoveAt/Find/Len; индекс вне границ — ошибка, не паника; quiet mode
- [ ] Типизированные события (ADR-0001): визит узла при обходе, переключение связи (с позициями затронутых узлов)
- [ ] Тесты шва 1: инвариант связности (обход от головы даёт ровно Len узлов), удаление головы/хвоста, поиск отсутствующего, операции на пустом списке; эмиттер-шпион фиксирует визиты узлов на известном сценарии
- [ ] Frame Renderer списка поверх kind'а «structure»: идентичность `linked-list`, значения в порядке следования, подсветки (посещён/добавлен/удалён), указатель head
- [ ] Маршрут `GET /api/run/linked-list` по шаблону: парсинг → валидация → runStreaming
- [ ] Тест шва 2: сценарий с find/вставкой → SSE-поток → ожидаемая последовательность кадров (виден обход)
- [ ] Фронт: новая разновидность ветки kind'а «structure» — узлы со стрелками next, разрывы между узлами, указатель head, подсветка узла обхода; слайсовые рендеры не тронуты
- [ ] Тесты шва 4: рендер разновидности linked-list
- [ ] `go build/vet/test` и фронт lint/test/build зелёные

## Notes

- Адреса памяти узлов не показываем (out of scope модуля) — стрелки схематичны.
- Двусвязный/циклический списки, Reverse/Sort — out of scope.
