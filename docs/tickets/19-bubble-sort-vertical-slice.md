# 19: Bubble sort — сквозной вертикальный срез

**What to build:** учащийся может выбрать bubble sort, задать массив целых чисел и увидеть, как последовательные сравнения и обмены упорядочивают его по возрастанию.

**Blocked by:** None (can start after пользовательский черновик и Ч2.5).

**Status:** ready-for-agent

Спека: `docs/SPEC.md`, модуль «Простые сортировки».

`автор-черновик: человек` — пользователь пишет черновик bubble sort в библиотеке алгоритмов и явно подтверждает его на Ч2.5; до этого реализация не начинается.

## Acceptance Criteria

- [ ] Библиотечный bubble sort сортирует переданный `[]int` по возрастанию на месте, поддерживает пустой и одноэлементный входы, отрицательные числа и дубликаты; меняет местами только строго убывающие соседние пары, поэтому остаётся устойчивым, и завершает работу после прохода без обменов.
- [ ] В quiet mode алгоритм не эмитирует события; с Emitter типизированные события сравнения и обмена содержат достаточно данных для восстановления шага. Публичные тесты проверяют результат и известную последовательность событий.
- [ ] Run позволяет выбрать bubble sort и передать список целых чисел; пустой массив допустим, длина ограничена 100 элементами. Некорректный ввод и превышение лимита отвергаются до начала SSE.
- [ ] Сортировка использует отдельный `kind="sort"`: исходный кадр и кадр на каждое событие — самодостаточные снимки всего массива с подсветкой сравниваемых/изменяемых индексов и пояснением на русском. Контракт `kind="array"` бинарного поиска не меняется.
- [ ] Фронтенд позволяет выбрать bubble sort, зеркально валидирует ввод до Run и показывает кадры сравнений и обменов. Публичные тесты покрывают разбор ввода и рендер поддерживаемого/некорректного снимка; существующие визуализации продолжают работать.
- [ ] Интеграционный тест SSE проверяет известный сценарий сортировки и итоговый массив; тесты также покрывают пустой вход и отказ на невалидном вводе/лимите до SSE.
- [ ] Go build/vet/test и lint, а также frontend lint/test/build проходят.
