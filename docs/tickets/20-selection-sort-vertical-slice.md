# 20: Selection sort — сквозной вертикальный срез

**What to build:** учащийся может выбрать selection sort в визуализаторе и наблюдать поиск минимума в неотсортированной части массива и его обмен с первым элементом этой части.

**Blocked by:** 19 (Bubble sort — сквозной вертикальный срез).

**Status:** done

Спека: `docs/SPEC.md`, модуль «Простые сортировки».

`автор-черновик: человек` — пользователь пишет черновик selection sort в библиотеке алгоритмов и явно подтверждает его на Ч2.5; до этого реализация не начинается.

## Acceptance Criteria

- [x] Библиотечный selection sort реализует утверждённый стандартный неустойчивый вариант: на каждом проходе выбирает минимум оставшейся части и меняет его местами с её первым элементом; сортирует `[]int` по возрастанию на месте, включая пустой/одноэлементный входы, отрицательные числа и дубликаты.
- [x] Quiet mode возвращает отсортированный результат без событий; типизированные события сравнения и обмена позволяют показать текущий минимум и финальный обмен прохода. Публичные тесты проверяют результат и известную последовательность событий.
- [x] Selection sort доступен в существующем интерфейсе запуска сортировок и использует общий контракт ввода и ограничение 100 элементов; сравнения и обмены отображаются самодостаточными `kind="sort"` кадрами с индексами и русскими пояснениями.
- [x] Интеграционные тесты проверяют SSE-кадры и конечное состояние selection sort; публичные frontend-тесты подтверждают выбор алгоритма и рендер его кадров. Bubble sort и прежние визуализации продолжают работать без изменения их контрактов.
- [x] Go build/vet/test и lint, а также frontend lint/test/build проходят.
