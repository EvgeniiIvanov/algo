# 24: Дедупликация алгоритм-нейтральной обвязки простых сортировок

**What to build:** убрать дублирующуюся алгоритм-нейтральную обвязку визуальных потоков bubble, selection и insertion sort, накопившуюся по тикетам 19–21: тонкие HTTP-обработчики (`visual/server/sort.go`), сборщики URL и диспетчинг на фронте (`visual/frontend/src/sse.ts`, `main.ts`), SSE-хелперы и каркасы тестов (`visual/server/sort_test.go`, `visual/frontend/tests/sortScenario.test.ts`) различаются только именем алгоритма — каждая следующая сортировка модуля умножает копии, а правка общего контракта входа требует синхронных правок в каждом экземпляре. Общая настройка входа рендереров (`visual/render/sort.go`) просматривается на предмет genuinely общего кода. Рефакторинг без смены поведения (поток D).

**Blocked by:** None

**Status:** in-progress

Источник записи: `docs/BACKLOG.md` (запись о дублировании обвязки сортировок; удаляется этим тикетом). Запись о тестах порядка модулей квиза остаётся в бэклоге для отдельного независимого тикета.

## Acceptance Criteria

- [ ] Маршруты, query-строки, валидация входа и лимит 100 элементов, последовательность и содержимое SSE-кадров, выбор алгоритма/URL/рендеринг на фронте — всё наблюдаемое поведение сохранено в точности: алгоритмы, события, схема кадров и пользовательские тексты не меняются.
- [ ] Дубликаты обвязки убраны только там, где код алгоритм-нейтрален: один параметризуемый обработчик сортировок на сервере (маршруты регистрируются по-алгоритмно), один сборщик URL простых сортировок на фронте, общие SSE-хелперы и каркасы тестов. Сопоставление «событие → кадр» и русские пояснения каждой сортировки остаются раздельными и читаемыми (`visual/render/sort.go`, ветка `renderSort` на фронте).
- [ ] Специфичные для алгоритма тест-сценарии сохранены полностью: сильные посеквенционные проверки кадров, пояснений и состояния вставки не ослаблены; общие хелперы выносят только повторяющуюся настройку (запрос, валидационная таблица, сверка с рендерером, тривиальные входы, порядок шагов) — каждая сортировка продолжает проверяться на своём маршруте.
- [ ] Спекулятивных обобщений нет: абстракции покрывают только существующие три потока простых сортировок; прочие алгоритмы, `PROGRESS.md`, библиотека `algorithms/` и квиз не затронуты.
- [ ] В `docs/WORKFLOWS.md` поток D дополнен узким уточнением: тесты при рефакторинге правятся только из-за смены интерфейсов, выноса общих каркасов (обвязки) или прояснения/усиления ожиданий — ослаблять проверки (ассерты) и сокращать покрытие публичного поведения нельзя; остальной текст потока не переписан.
- [ ] Из `docs/BACKLOG.md` удалена только запись об обвязке сортировок.
- [ ] Go build/vet/test и lint, а также frontend lint/test/build (frozen install) проходят.
