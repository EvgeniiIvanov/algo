# 25: Общие тестовые хелперы для тестов порядка модулей квиза

**What to build:** вынести повторяющийся поиск блока `block-1` по id и поиск индексов модулей перебором их id из `TestEmbeddedBankBlock1HashTablesOrder` и `TestEmbeddedBankBlock1SimpleSortsAfterHashTables` (`quiz/bank_test.go`) в общие тестовые хелперы: оба теста дублируют обе логики, и следующий тест порядка модулей скопирует их ещё раз.
