# 30: Документация реализованных алгоритмов и структур

**What to build:** учащийся может открыть документацию в репозитории и увидеть, как устроены реализованные алгоритмы поиска и сортировки, а также основные структуры данных.

**Blocked by:** None (можно начать сразу).

**Status:** in-progress

**автор-черновик:** не применим — документационный тикет.

## Acceptance Criteria

- [ ] В `docs/algorithms/` есть индекс и документация по реализованным темам: бинарный поиск; bubble sort, selection sort, insertion sort, merge sort и quicksort; стек, очередь, список на слайсе, односвязный список и хеш-таблица.
- [ ] Для поиска и сортировок добавлены Mermaid-блок-схемы, отражающие именно реализованные варианты алгоритмов, а не обобщённый псевдокод.
- [ ] Для структур добавлены компактные схемы представления. Блок-схемы операций добавлены только там, где обход или обработка коллизий важны для понимания; отдельная схема для каждой операции не требуется.
- [ ] В корневом `README.md` есть ссылка на индекс документации; сами схемы в README не дублируются.
- [ ] В `docs/WORKFLOWS.md` зафиксировано требование добавлять документацию алгоритма или структуры в соответствующий библиотечный тикет после подтверждения пользовательского черновика на Ч2.5 и до завершения реализации. Документация сверяется с реализацией на ревью; новый чекпойнт не вводится.
- [ ] Mermaid-разметка и ссылки корректны и отображаются на GitHub. Изменения не затрагивают поведение приложения и `PROGRESS.md`.
