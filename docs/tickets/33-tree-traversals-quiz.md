# 33: Квиз по обходам бинарного дерева + отметка прогресса

**What to build:** учащийся может пройти квиз по in-order, pre-order, post-order и обходу по уровням и закрепить порядок посещения и базовые характеристики.

**Blocked by:** 31 (DFS-обходы), 32 (обход по уровням).

**Status:** draft (Ч2 pending)

Спека: `docs/SPEC.md`, модуль «Обходы бинарного дерева».

## Acceptance Criteria

- [ ] В Quiz Bank добавлен `block-2` («Блок 2. Деревья») и первым модулем — `tree-traversals` с 5–8 вопросами в существующем формате.
- [ ] Вопросы проверяют последовательность посещения на произвольном бинарном дереве для всех четырёх порядков, различие DFS и обхода по уровням, роль FIFO-очереди, время O(n) и базовое сравнение вспомогательной памяти. Вопросы и объяснения не предполагают, что дерево является BST, и не смешивают обход дерева с BFS графа.
- [ ] Валидация Quiz Bank проверяет формат вопросов, пояснения и ровно один правильный ответ; тесты проверяют наличие `block-2` и порядок его модулей, начиная с `tree-traversals`. Движок квиза не меняется.
- [ ] В `PROGRESS.md` отмечен модуль «Обходы (in / pre / post / по уровням)» только после завершения тикетов 31 и 32 и готовности квиза.
