# 36: BST — фронтенд сценария и кадров

**What to build:** учащийся задаёт сценарий BST во фронтенде, запускает его и видит сравнения и актуальное дерево на каждом кадре.

**Blocked by:** 35 (нужен контракт серверного Run и снимков).

**Status:** done

Спека: `docs/SPEC.md`, модуль «BST: вставка, поиск и удаление».

## Acceptance Criteria

- [ ] Во фронтенде доступен сценарий BST с командами `insert N`, `search N`, `delete N`; стартовое дерево пустое.
- [ ] Публичная проверка входа зеркалирует серверные правила синтаксиса, диапазон целых `[-(2^53−1), 2^53−1]`, лимит 500 команд и максимум 100 живых узлов; Run URL корректно кодирует `script` для `GET /api/run/bst` и совпадает с серверным контрактом.
- [ ] Кадры `kind="tree"` с BST-снимками принимаются и рендерятся: активный путь сравнения, результат шага и обновлённая топология видны без предположения о постоянстве ID между кадрами.
- [ ] Публичные тесты проверяют допустимый/недопустимый сценарий, построение URL и рендер кадров вставки, поиска, промаха и удаления с двумя детьми.
- [ ] UI и фронтенд-тесты прежних обходов бинарного дерева продолжают работать без изменения их поведения.
- [ ] `pnpm install --frozen-lockfile`, `pnpm lint`, `pnpm test` и `pnpm build` проходят.
