# 42: Trie — фронтенд сценария и кадров

**What to build:** учащийся задаёт сценарий Trie во фронтенде, запускает его и видит обход по rune, отметки конца слова и изменённое дерево на каждом кадре.

**Blocked by:** 41 (нужен контракт серверного Run и снимков `kind="trie"`).

**Status:** planned

Спека: `docs/SPEC.md`, модуль «Trie: вставка, поиск, префиксы и удаление».

## Acceptance Criteria

- [ ] Во фронтенде доступен сценарий Trie с командами `insert W`, `search W`, `prefix W`, `delete W`; стартовое дерево пустое.
- [ ] Публичная проверка входа зеркалирует серверные правила: один непустой Unicode-токен без пробелов, до 100 rune в слове/префиксе, до 500 команд и до 100 живых rune-узлов (корень не считается); Run URL корректно кодирует `script` для `GET /api/run/trie` и совпадает с серверным контрактом.
- [ ] Кадры `kind="trie"` принимаются и рендерятся: произвольное ветвление, отметки конца слова, активный путь и результат шага видны в каждом снимке.
- [ ] Публичные тесты проверяют допустимый/недопустимый сценарий, построение URL и рендер кадров вставки с общим префиксом, точного поиска и промаха, проверки префикса и удаления с pruning.
- [ ] UI и фронтенд-тесты прежних визуализаций (обходы, BST) продолжают работать без изменения их поведения; контракт `kind="tree"` не меняется.
- [ ] `pnpm install --frozen-lockfile`, `pnpm lint`, `pnpm test` и `pnpm build` проходят.
