# 45: Графы — библиотечная модель, представления и преобразования

**What to build:** учащийся может построить невзвешенный граф из числа вершин и списка рёбер в режимах directed/undirected, получить его список смежности и матрицу смежности, преобразовать одно представление в другое и проверить всё это как обычную библиотеку без визуализатора.

**Blocked by:** None (первый тикет модуля «Основы графов»; реализация не начинается до утверждения спеки на Ч1 и тикетов на Ч2 и до пользовательского черновика на Ч2.5).

**Status:** in-progress — ожидает пользовательский черновик на Ч2.5

Спека: `docs/SPEC.md`, модуль «Основы графов: представления, DFS, BFS и циклы».

`автор-черновик: человек` — пользователь пишет черновик модели графа, представлений и преобразований в `algorithms/graphs` и явно подтверждает его на Ч2.5; до этого реализация не начинается. Точные Go-сигнатуры и формы ошибок задаёт черновик; семантика ниже обязательна и не ослабляется сигнатурами. Учебная документация `docs/algorithms/` (модель графа и представления) добавляется после подтверждения черновика и до завершения тикета.

## Acceptance Criteria

- [ ] В `algorithms/graphs` есть общая модель невзвешенного графа: вершины — целые ID `0..n-1`; граф поддерживает режимы directed и undirected. Сигнатуры и форма API — по пользовательскому черновику (Ч2.5).
- [ ] Граф строится из числа вершин и списка рёбер; каждое ребро — пара вершин в диапазоне `0..n-1`. Параллельные и дублирующие рёбра отклоняются ошибкой (не паникой и не молчаливым дедупом); дубликат — совпадающая пара с учётом режима: в undirected `(u,v)` и `(v,u)` — одно и то же ребро и дубликат входа, в directed противоположные направления — разные рёбра. Индекс вне диапазона — ошибка. Петля (self-loop) разрешена и сохраняется.
- [ ] Изолированные вершины и несвязные графы валидны и сохраняются без потерь.
- [ ] Доступны два представления: список смежности и матрица смежности (логическая V×V; в directed несимметрична, в undirected симметрична, у петли диагональная ячейка). Соседи в списке перечисляются в порядке возрастания номеров вершин — это делает обходы тикетов 46–48 детерминированными; порядок посещения в выходах DFS/BFS остаётся фактическим порядком обхода и не сортируется по возрастанию.
- [ ] Есть преобразования в обе стороны: список → матрица и матрица → список, с сохранением петель и ошибки на несоответствующую размеру входа. Список → матрица сохраняет режим самого графа; матрица → список получает режим от вызывающего — сама матрица направление не кодирует. В undirected несимметричный вход нормализуется (OR): единица в любой из пары симметричных ячеек `m[u][v]` / `m[v][u]` означает одно ребро `{u, v}` — поведение зафиксировано тестом.
- [ ] Quiet mode работает без событий; типизированные события не обязательны для этого тикета (алгоритмических шагов нет), но пакет не импортирует `visual/` и `quiz/` (ADR-0001).
- [ ] Публичные тесты (quiet mode) покрывают: пустой граф (0 вершин), одна вершина, изолированные вершины, несвязный граф, directed и undirected режимы, ошибку дублирующего ребра в обоих режимах (в undirected `(u,v)` и `(v,u)` — один и тот же дубликат; в directed противоположные направления различны и оба принимаются), ребро вне диапазона, петлю, возрастающий порядок соседей и round-trip преобразований (список → матрица → список даёт исходный граф). Внутреннее устройство (хранение списка) не фиксируется.
- [ ] `docs/algorithms/` содержит учебное описание модели и представлений с записью в индекс `docs/algorithms/README.md`; документация отражает реализованный вариант и не утверждает чужие режимы.
- [ ] Алгоритмы (DFS, BFS, циклы) в этом тикете не реализуются: тикеты 46–48 строят их поверх списка смежности.
- [ ] `go build ./...`, `go vet ./...`, `go test ./...` и `golangci-lint run ./...` проходят.
- [ ] Имплементор не меняет `PROGRESS.md`: строка модуля отмечается оркестратором после мержа всех обязательных тикетов (45–49).
